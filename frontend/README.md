# CampusFix AI Frontend

This is the Phase 1 frontend foundation for CampusFix AI.

## Stack

- React 18
- Vite 5
- JavaScript
- CSS custom properties
- react-router-dom v6

## Notes

- Phase 1 is a foundation shell only.
- Real backend calls are intentionally gated behind fixture mode.
- Use environment variables via `import.meta.env`.
